1. 快速开始

只需要 3 个参数：

  • Base URL: https://fucaixie.xyz/v1
  • API Key: fk-xxxxxxxxxxxx
  • Model: gpt-4o
curl https://fucaixie.xyz/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer fk-xxx" \ -d '{ "model": "gpt-4o", "messages": [{"role": "user", "content": "你好"}] }'

3. 常见错误

  • 401: Key 错误或过期
  • 404: Base URL 没带 /v1
  • 429: 频率过快
